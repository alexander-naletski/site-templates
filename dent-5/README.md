# Шаблон сайта стоматологии №5 — «блеск.»

Одностраничный адаптивный сайт на чистом HTML + CSS + JavaScript — бьюти-стиль бренда косметики и ухода за кожей.
Без сборки и без зависимостей: откройте `index.html` двойным кликом — сайт работает.
Для публикации загрузите папку целиком на любой хостинг (GitHub Pages, Netlify, обычный хостинг) — все пути относительные, все файлы локальные.

> ⚠️ Всё наполнение — **демо-данные**: название «блеск.», город, телефоны, адрес, цены, врачи, отзывы и реквизиты вымышлены. Люди на фото — модели фотостоков.
> Медицинская реклама: перед публикацией проверьте тексты на соответствие законодательству (в подвале уже есть строка «Имеются противопоказания, необходима консультация специалиста»), укажите реальные лицензию и реквизиты.

Дизайн создан по принципам сайта из другой отрасли: **https://www.glossier.com/** (косметика и уход за кожей (beauty e-commerce)). Логотипы, тексты и изображения референса не использовались — подробности в `docs/DESIGN-NOTES.md`.

## Структура

```
dent-5/
├── index.html      ← каркас страницы (обычно не трогаем)
├── config.js       ← ВЕСЬ КОНТЕНТ: название, контакты, услуги, цены, врачи, тексты, отзывы, FAQ
├── theme.css       ← ЦВЕТА, шрифты, скругления (CSS-переменные)
├── skin.css        ← оформление ЭТОГО дизайна: раскладка блоков, эффекты, анимации
├── assets/
│   ├── favicon.svg
│   ├── fonts/      ← шрифты дизайна (локально, с кириллицей, OFL)
│   └── img/        ← фотографии (WebP, по 2 размера: -640 и -1024) + og-image.jpg
├── core/           ← «движок»: общий для всех шаблонов (не редактировать)
├── tools/          ← optimize-images.py (подготовка фото), prerender.js (SEO)
├── screenshots/    ← превью шаблона (для витрины, на сайт не влияют — можно удалить)
└── docs/           ← заметки по дизайну и источники фото
```

**Правило:** для нового клиента меняем `config.js`, `theme.css` и файлы в `assets/`. `skin.css` — если нужно подправить внешний вид. Папку `core/` не трогаем.

## 1. Название, телефон, адрес

Откройте `config.js` и измените значения в кавычках: `brand` (название, текстовый логотип), `contacts` (телефон, адрес, часы работы, соцсети), `meta.title` и `meta.description` (заголовок вкладки и описание для поисковиков), `footer.legal` (реквизиты, номер лицензии), `footer.demoNote`.

**Перед сдачей клиенту** поставьте `demo: false` в начале `config.js` — исчезнут пометки «пример» и «демо-режим».

## 2. Цвета и шрифты

Всё в `theme.css`. Главное:

```css
--color-accent: #111111;        /* чёрные кнопки */
--color-blush: #f6dcd8;         /* пудровый: блоки, бейджи */
--color-cherry: #d9383a;        /* красный стикер «хит» */
```

Шрифты: Golos Text (заголовки и текст) + IBM Plex Mono (мелкие подписи) — в `assets/fonts/`. Чтобы заменить шрифт — положите `.woff2` в `assets/fonts/`, поправьте `@font-face` в начале `theme.css` и переменные `--font-main` / `--font-heading`.

## 3. Блоки этого дизайна

Порядок блоков = порядок в `sections` в `config.js`; скрыть блок — `hidden: true`. Особенности этого шаблона:

- **Полоса-объявление** — `header.announce` (+ `announceHref`) — чёрная строка над шапкой (акция).
- **Первый экран** — `variant: "cover"` — белая карточка с текстом и кнопкой слева сверху, огромная строчная подпись по центру снизу.
- **«Настроения»** — `type: "gallery"` с `id: "looks"` — 5 фото 4:5 с подписью поверх (на телефоне — лента).
- **Услуги-витрина** — сетка 4 колонки как карточки товаров; `badge: "хит"` / `"новинка"` — круглый стикер на фото.
- **О нас** — `variant: "reverse"` на пудровом фоне.
- **Цены** — вкладки.
- **Отзывы** — `variant: "grid"` (на телефоне — лента).
- **Врачи** — `type: "team"` — курсивные монограммы на пудровом/сером.

## 4. Услуги, цены, врачи, тексты

- **Услуги** — массив `services`: `title`, `text`, `price`, `time`, `icon`, `image` (фото, нужно для этого дизайна). Услуги автоматически попадают в блок услуг, мобильное меню, подвал и список формы записи; клик по услуге подставляет её в форму.
- **Цены** — блок `type: "prices"` → `categories` → `rows`: `["Процедура", "Цена"]`.
- **Врачи** — блок `type: "team"` → `items`: `name`, `role`, `exp` (стаж), `text`, `tags`, `service` (какая услуга подставится в форму), `image` (необязательно — без фото рисуется монограмма из инициалов).
- **Отзывы, FAQ, шаги, статистика** — соответствующие блоки в `sections`.
- Стоматологические иконки: `tooth, implant, braces, crown, scan, smile, baby, heart, syringe, leaf, drop, sparkles, shield, wallet, calendar, clock, users` и др. (см. `core/icons.js`).

## 5. Фотографии

Каждое фото хранится в двух размерах: `name-640.webp` и `name-1024.webp`. В `config.js` путь указывается **без** окончания: `image: "assets/img/svc-implant"`.

```bash
pip install pillow
python3 tools/optimize-images.py мое-фото.jpg assets/img/svc-implant --ratio 4:3
```

Пропорции в этом дизайне: первый экран — `16:9`, «настроения» — `4:5`, **услуги — `1:1`** (витрина), «О нас» — `4:5`.
Без программ: пережмите фото на https://squoosh.app в WebP шириной 640 и 1024 px.
Фото пациентов и работ «до/после» публикуйте только с письменного согласия пациента.

## 6. Карта и форма записи

- Карта: в `contacts.mapEmbed` вставьте `src` из кода виджета Яндекс Карт. Пока пусто — показывается заглушка с кнопкой «Открыть на карте» (`contacts.mapLink`).
- Форма работает в демо-режиме (проверяет поля, показывает успех, **ничего не отправляет**). Чтобы получать заявки — укажите `endpoint` в блоке `booking` (Formspree, Getform, свой скрипт, вебхук Telegram-бота): форма отправит POST с JSON `name, phone, service, date, time, comment, consent` (+ `car` — если включено дополнительное поле). Там же: `phoneMask`, `timeSlots`, `closedWeekdays` (0 — вс, 6 — сб), `maxDaysAhead`, `carField: false` — убрать дополнительное поле, `carOptional: true` — сделать его необязательным, подпись — `labels.car` (в стоматологии, например, «кто пациент»).

## 7. SEO и пререндер (по желанию)

В `index.html` «запечена» готовая разметка для поисковиков и превью. После правок `config.js` обновите её (нужен Node.js): `npm i puppeteer && node tools/prerender.js`. Если забыть — сайт сам отрисует актуальный контент из `config.js`.
Для превью в соцсетях после публикации укажите в `meta.ogImage` полный адрес: `https://ваш-домен.by/assets/img/og-image.jpg`.

## 8. Публикация

- **Netlify:** перетащите папку на app.netlify.com/drop.
- **GitHub Pages:** загрузите содержимое папки в репозиторий → Settings → Pages → Branch: main / root.
- **Обычный хостинг:** загрузите содержимое папки в `public_html`.

## Особенности

- Адаптивность 320 px – 4K (проверено на 360 / 390 / 414 / 820 / 1280 / 1440 px), мобильное меню, нижняя панель «Позвонить / Записаться» на телефонах, горизонтальные ленты со свайпом.
- WebP в двух размерах, `loading="lazy"`, шрифты локально, без библиотек и внешних запросов.
- Анимации только opacity/transform; при «уменьшить движение» (`prefers-reduced-motion`) отключаются.
- Доступность: семантичная разметка, управление с клавиатуры, подписи для скринридеров.
