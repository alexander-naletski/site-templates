# Заметки по дизайну — «Кадр» (агроусадьба №4)

**Референс:** https://a24films.com/ — независимая кинокомпания (film studio).
Взяты только принципы визуального стиля и интерфейса. Логотипы, тексты, фотографии и код референса **не использовались**; все фото — CC0 (см. `IMAGE-CREDITS.md`), тексты написаны с нуля, название усадьбы вымышлено.

Скриншоты референса (для внутреннего использования, в архив не входят): `/workspace/sites/_reference/a24/`

## Что взято из референса (принципы)

- Чёрный экран, белый текст, ноль скруглений, тонкие серые рамки #222.
- Логотип по центру и «Меню» слева поверх полноэкранного кадра.
- Первый экран — огромный список названий (у киностудии — фильмы, у нас — дома с вместимостью) плотным гротеском с отрицательной разрядкой.
- Моноширинные подписи и кнопки капсом (Roboto Mono), плотный гротеск Arimo для заголовков.
- Контрастная светлая «витрина» внутри тёмной страницы; кадры в ч/б, цвет при наведении; «плёночная» цветокоррекция с зерном.

## Чем этот шаблон отличается от остальных шаблонов усадеб

Единственный тёмный шаблон: «афиша» домов в первом экране, моноширинные подписи, ч/б галерея-раскадровка, аренда локации для съёмок. Для атмосферных усадеб, фото- и кинолокаций, вечеринок.

## Где что настраивается

- `theme.css` — цвета, шрифты, скругления.
- `skin.css` — раскладка и эффекты этого дизайна (переопределяет общий движок `core/core.css`).
- `config.js` — варианты блоков (`variant: ...`), тексты и порядок секций.
