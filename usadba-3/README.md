# Шаблон сайта агроусадьбы №3 — «Тихая»

Одностраничный адаптивный сайт загородного комплекса / агроусадьбы на чистом HTML + CSS + JavaScript — спокойный журнальный стиль «медленной жизни».
Без сборки и без зависимостей: откройте `index.html` двойным кликом — сайт работает.
Для публикации загрузите папку целиком на любой хостинг (GitHub Pages, Netlify, обычный хостинг) — все пути относительные, все файлы локальные.

> ⚠️ Всё наполнение — **демо-данные**: название «Тихая», место (Березинский район, 105 км от Минска), телефоны, адрес, координаты, цены, отзывы и реквизиты вымышлены. Фото иллюстративные (CC0), это не фотографии реальной усадьбы.

Дизайн создан по принципам сайта из другой отрасли: **https://www.kinfolk.com/** (независимый журнал о стиле жизни (editorial magazine)). Логотипы, тексты и изображения референса не использовались — подробности в `docs/DESIGN-NOTES.md`.

## Структура

```
usadba-3/
├── index.html      ← каркас страницы (обычно не трогаем)
├── config.js       ← ВЕСЬ КОНТЕНТ: название, контакты, дома, доп. услуги, праздники, цены, тексты, отзывы, FAQ, дорога
├── theme.css       ← ЦВЕТА, шрифты, скругления (CSS-переменные)
├── skin.css        ← оформление ЭТОГО дизайна: раскладка блоков, эффекты
├── assets/
│   ├── favicon.svg
│   ├── fonts/      ← шрифты дизайна (локально, с кириллицей, OFL)
│   └── img/        ← фотографии (WebP, по 2 размера: -640 и -1024) + og-image.jpg
├── core/           ← «движок»: общий для всех шаблонов (не редактировать)
├── tools/          ← optimize-images.py (подготовка фото), prerender.js (SEO)
├── screenshots/    ← превью шаблона (для витрины, на сайт не влияют — можно удалить)
└── docs/           ← заметки по дизайну и источники фото
```

**Правило:** для нового клиента меняем `config.js`, `theme.css` и файлы в `assets/`. `skin.css` — если нужно подправить внешний вид. Папку `core/` не трогаем.

## 1. Название, телефон, адрес

Откройте `config.js` и измените значения в кавычках: `brand` (название, текстовый логотип), `contacts` (телефон, адрес, время заезда/выезда в `hours`, соцсети), `meta.title` и `meta.description` (заголовок вкладки и описание для поисковиков), `footer.legal` (реквизиты, номер свидетельства агроэкоусадьбы), `footer.demoNote`.

**Перед сдачей клиенту** поставьте `demo: false` в начале `config.js` — исчезнут пометки «пример» и «демо-режим».

## 2. Цвета и шрифты

Всё в `theme.css`. Главное:

```css
--color-accent: #1a1a1a;        /* почти чёрный: кнопки */
--color-bg-soft: #dbded5;       /* шалфейные плоскости */
/* --milk: #fbfaf6 — молочный фон страницы, в skin.css */
```

Шрифты: Literata 300–500 (заголовки) + IBM Plex Sans 400–600 (текст), в `assets/fonts/`. Чтобы заменить шрифт — положите `.woff2` в `assets/fonts/`, поправьте `@font-face` в начале `theme.css` и переменные `--font-main` / `--font-heading`.

## 3. Блоки этого дизайна

Порядок блоков = порядок в `sections` в `config.js`; скрыть блок — `hidden: true`. Особенности этого шаблона:

- **Шапка** — `header.align: "center"` — логотип по центру, меню по бокам, контурная кнопка.
- **Первый экран** — `variant: "editorial"` — «обложка выпуска»: два вертикальных фото, надпись «Выпуск 14 · Лето», заголовок антиквой прописными.
- **Манифест** — `type: "statement"` — крупная цитата по центру.
- **Дома** — `variant: "rows"`, `showNum: true` — строки-«статьи» с нумерацией 01 / 05 на шалфейном фоне.
- **Баннер** — `type: "banner", variant: "full"`, текст по центру.
- **Доп. услуги** — 4 колонки вертикальных фото, баня выделена.
- **Ужины и чаепития** — `type: "programs"` на шалфейном фоне.
- **Галерея** — `variant: "mosaic"` — журнальная мозаика.
- **Подвал** — `footer.bigText` — огромное название усадьбы.

## 4. Дома, доп. услуги, праздники, цены

- **Дома** — массив `services` в начале `config.js`. Поля: `id` (латиницей, обязательно), `title`, `text`, `guests` (основных мест), `extraBeds` (доп. мест), `beds` («3 спальни»), `area` («120 м²»), `amenities` (удобства — список), `night` (цена за сутки Вс–Чт, число), `weekend` (цена Пт и Сб, число), `price` (текст «от 380 BYN» для карточки), `badge`, `icon`, `image`. Дома автоматически попадают в блок «Дома», мобильное меню, подвал, поиск дат и форму брони; по `guests + extraBeds` форма ограничивает число гостей, по `night`/`weekend` — считает стоимость.
- Настройки блока `type: "stays"`: `perNight` («за сутки»), `weekendLabel` («Пт–Сб»), `buttonText`, `buttonStyle`, `variant` (`rail` — лента, `rows` — строки), `showNum: true` — нумерация, `note` — сноска.
- **Доп. услуги** — блок `type: "extras"` → `items`: `id` (обязательно — по нему услуга появляется галочкой в форме), `title`, `short` (короткое название для формы), `text`, `price` + `unit` (текст на карточке), `cost` (число для расчёта; нет `cost` — «по запросу»), `per`: `"night"` — за каждую ночь, `"guest"` — с гостя, `"guestNight"` — с гостя за ночь, без `per` — разово; `icon`, `image`. Кнопка на карточке отмечает услугу в форме брони.
- **Праздники и события** — блок `type: "programs"` → `items`: `id` (попадает в форму отдельной группой `groupLabel`), `title`, `for`, `items` (что входит), `price`, `badge`, `image`. Для события дата выезда в форме необязательна.
- **Цены** (если есть блок `type: "prices"`) — `categories` → `rows`: `["Услуга", "Цена"]`.
- **Галерея** — блок `type: "gallery"` → `items`: `title`, `image`; `lightbox: true` — просмотр на весь экран (стрелки, свайп, Esc).
- **Как доехать** — блок `type: "route"`: `distance`, `distanceNote`, `coords` (кнопка «Копировать»), `links` (навигаторы), `items` (варианты дороги: `icon`, `title`, `meta`, `text`), `note`.
- Иконки: `home, flame, waves, tree, sun, snow, bike, paw, utensils, coffee, gift, heart, music, users, car, bus, train, navigation, pin, calendar` и др. (см. `core/icons.js`).

## 5. Фотографии

Каждое фото хранится в двух размерах: `name-640.webp` и `name-1024.webp`. В `config.js` путь указывается **без** окончания: `image: "assets/img/stay-lodge"`.

```bash
pip install pillow
python3 tools/optimize-images.py мое-фото.jpg assets/img/stay-lodge --ratio 4:3
```

Пропорции в этом дизайне: **первый экран, доп. услуги и события — `4:5`** (журнальные вертикали), дома — `4:3`, баннер — `16:9`, галерея — `3:2` (мозаика).
Без программ: пережмите фото на https://squoosh.app в WebP шириной 640 и 1024 px.

## 6. Карта и форма бронирования

- Карта: в `contacts.mapEmbed` вставьте `src` из кода виджета Яндекс Карт. Пока пусто — показывается заглушка с кнопкой «Открыть на карте» (`contacts.mapLink`).
- Форма (`type: "booking"`, `mode: "stay"`) — бронирование по датам: дом или событие, заезд, выезд, взрослые и дети (с ограничением по вместимости дома), доп. услуги галочками и **предварительный расчёт** (будни/выходные + услуги). Настройки: `minNights`, `maxNights`, `maxDaysAhead`, `groupMax` (максимум гостей для событий), `labels` (подписи полей), `estimateNote`, `perks`, `successTitle`, `successText`.
- Форма работает в демо-режиме (проверяет поля, показывает успех со сводкой, **ничего не отправляет**). Чтобы получать заявки — укажите `endpoint` (Formspree, Getform, свой скрипт, вебхук Telegram-бота): форма отправит POST с JSON `name, phone, service, date, dateout, adults, kids, extras[], comment, consent`.
- Проверка дат (`type: "finder"`) не бронирует сама — переносит выбор в форму и прокручивает к ней. Подключить реальный календарь занятости (например, модуль бронирования или Google Календарь) можно, заменив `endpoint` на свой обработчик.

## 7. SEO и пререндер (по желанию)

В `index.html` «запечена» готовая разметка для поисковиков и превью. После правок `config.js` обновите её (нужен Node.js): `npm i puppeteer && node tools/prerender.js`. Если забыть — сайт сам отрисует актуальный контент из `config.js`.
Для превью в соцсетях после публикации укажите в `meta.ogImage` полный адрес: `https://ваш-домен.by/assets/img/og-image.jpg`.

## 8. Публикация

- **Netlify:** перетащите папку на app.netlify.com/drop.
- **GitHub Pages:** загрузите содержимое папки в репозиторий → Settings → Pages → Branch: main / root.
- **Обычный хостинг:** загрузите содержимое папки в `public_html`.

## Особенности

- Адаптивность 320 px – 4K (проверено на 360 / 390 / 414 / 820 / 1280 / 1440 px), мобильное меню, нижняя панель «Позвонить / Забронировать» на телефонах, горизонтальные ленты со свайпом.
- WebP в двух размерах, `loading="lazy"`, шрифты локально, без библиотек и внешних запросов.
- Анимации только opacity/transform; при «уменьшить движение» (`prefers-reduced-motion`) отключаются.
- Доступность: семантичная разметка, управление с клавиатуры (в т.ч. просмотр фото), подписи для скринридеров.
