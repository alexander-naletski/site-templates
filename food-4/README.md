# Шаблон сайта общепита №4 — «Печь 900» (пиццерия и стрит-фуд)

Одностраничный адаптивный сайт кафе / ресторана на чистом HTML + CSS + JavaScript — яркий игровой стиль мобильной игровой студии: плашки, пилюли, сочные цвета.
Без сборки и без зависимостей: откройте `index.html` двойным кликом — сайт работает.
Для публикации загрузите папку целиком на любой хостинг (GitHub Pages, Netlify, обычный хостинг) — все пути относительные, все файлы локальные.

> ⚠️ Всё наполнение — **демо-данные**: название «Печь 900», город (Брест), телефоны, адрес, меню, цены, отзывы и реквизиты вымышлены. Фото иллюстративные (CC0), это не блюда и интерьеры реального заведения.

Дизайн создан по принципам сайта из другой отрасли: **https://supercell.com/** (студия мобильных игр (gaming studio)). Логотипы, тексты и изображения референса не использовались — подробности в `docs/DESIGN-NOTES.md`.

## Структура

```
food-4/
├── index.html      ← каркас страницы (обычно не трогаем)
├── config.js       ← ВЕСЬ КОНТЕНТ: название, контакты, график, меню и цены, события, тексты, отзывы, FAQ, бронь
├── theme.css       ← ЦВЕТА, шрифты, скругления (CSS-переменные)
├── skin.css        ← оформление ЭТОГО дизайна: раскладка блоков, эффекты
├── assets/
│   ├── favicon.svg
│   ├── fonts/      ← шрифты дизайна (локально, с кириллицей, OFL)
│   └── img/        ← фотографии (WebP, по 2 размера: -640 и -1024) + og-image.jpg
├── core/           ← «движок»: общий для всех шаблонов (не редактировать)
├── tools/          ← optimize-images.py (подготовка фото), prerender.js (SEO)
├── screenshots/    ← превью шаблона (для витрины, на сайт не влияют — можно удалить)
└── docs/           ← заметки по дизайну и источники фото
```

**Правило:** для нового клиента меняем `config.js`, `theme.css` и файлы в `assets/`. `skin.css` — если нужно подправить внешний вид. Папку `core/` не трогаем.

## 1. Название, телефон, адрес

Откройте `config.js` и измените значения в кавычках: `brand` (название, текстовый логотип), `contacts` (телефон, адрес, часы работы в `hours`, график для статуса «открыто/закрыто» в `schedule`, соцсети), `meta.title` и `meta.description` (заголовок вкладки и описание для поисковиков), `footer.legal` (реквизиты), `footer.demoNote`.

**Перед сдачей клиенту** поставьте `demo: false` в начале `config.js` — исчезнут пометки «пример» и «демо-режим».

## 2. Цвета и шрифты

Всё в `theme.css`. Главное:

```css
--color-accent: #1464ff;        /* синий: кнопки-пилюли, блок доставки */
/* #ffd21f жёлтый, #ff3e8a розовый, #18b56b зелёный — «таблетки» в skin.css */
```

Шрифты: Unbounded 600–900 (заголовки) + Onest 400–700 (текст), в `assets/fonts/`. Чтобы заменить шрифт — положите `.woff2` в `assets/fonts/`, поправьте `@font-face` в начале `theme.css` и переменные `--font-main` / `--font-heading`.

## 3. Блоки этого дизайна

Порядок блоков = порядок в `sections` в `config.js`; скрыть блок — `hidden: true`. Особенности этого шаблона:

- **Шапка** — чёрная плашка со скруглением внутри контейнера, жёлтая строка «Доставка бесплатно от 40 BYN».
- **Первый экран** — `variant: "collage", layout: "center"` — заголовок, текст и кнопки по центру между двумя наклонёнными фото.
- **Что у нас** — `type: "gallery", variant: "cards"` — 4 крупные карточки 2×2 с цветными «таблетками»-подписями и ссылками (`href`).
- **Меню** — `type: "menu"` — вкладки: пицца (10), стрит-фуд (8), напитки.
- **Доставка** — `type: "order"` — синий блок с жёлтой кнопкой.
- **Праздники** — `type: "programs"` — день рождения, детский мастер-класс, фудтрак.
- **Галерея** — 8 фото, `lightbox: true`.

## 4. Меню, доставка, события

- **Меню** — блок `type: "menu"` → `categories`: `id` (латиницей — категория попадает в выпадающее меню шапки, мобильное меню и подвал), `title`, `icon`, `note`, `items`. Блюдо: `title`, `text` (состав), `weight` (выход: «250 г», «300 мл»), `price` (строка: «12,90»), `oldPrice`, `image`, `imageAlt`, `tags` (метки: «Хит», «Вег», «Веган», «Острое», «Без глютена» — с иконками), `badge`, `featured`.
- Настройки блока меню: `variant` (`grid` — карточки с фото, `list` — строки с точками, без фото), `tabs: false` — все категории подряд без вкладок, `note`, `buttonText`/`buttonHref`. На странице может быть несколько блоков меню (например, основное и винная карта).
- **Доставка и навынос** — блок `type: "order"`: `title`, `text`, `points` (`icon` + `text`), `buttons` (`text`, `href` — ссылка на бот, сервис доставки или `tel:`, `style`, `icon`), `note`, `image`.
- **События и банкеты** — блок `type: "programs"` → `items`: `id` (попадает в форму брони группой `groupLabel`), `title`, `for`, `items`, `price`, `badge`, `image`, `featured`.
- **Статус «Открыто / закрыто»** — `contacts.schedule`: 7 пар `["открытие", "закрытие"]` с воскресенья по субботу, `null` — выходной; работает и после полуночи («01:00»). Включается на первом экране `openStatus: true`, выводится и в контактах.
- **Галерея** — блок `type: "gallery"` → `items`: `title`, `image`, `alt`, `text`, `href`; `lightbox: true` — просмотр на весь экран (стрелки, свайп, Esc).
- Иконки: `utensils, coffee, cup, wine, beer, pizza, burger, croissant, cake, wheat, leaf, flame, fish, chef, bag, scooter, gift, clock, star, sparkles` и др. (см. `core/icons.js`).

## 5. Фотографии

Каждое фото хранится в двух размерах: `name-640.webp` и `name-1024.webp`. В `config.js` путь указывается **без** окончания: `image: "assets/img/d-pasta"`.

```bash
pip install pillow
python3 tools/optimize-images.py мое-фото.jpg assets/img/d-pasta --ratio 4:3
```

Пропорции в этом дизайне: первый экран и карточки «Что у нас» — `4:3`, пицца и стрит-фуд — `1:1`, события — `4:3`, галерея — `3:2`.
Без программ: пережмите фото на https://squoosh.app в WebP шириной 640 и 1024 px.

## 6. Карта и бронирование столов

- Карта: в `contacts.mapEmbed` вставьте `src` из кода виджета Яндекс Карт. Пока пусто — показывается заглушка с кнопкой «Открыть на карте» (`contacts.mapLink`).
- Форма (`type: "booking"`, `mode: "table"`) — бронь столика: имя, телефон, дата, время, число гостей (кнопки − / +), зал или событие, комментарий. Настройки: `timeSlots` (время брони), `slotsByDay` (своё время для дней недели: `0` — воскресенье … `6` — суббота), `closedWeekdays` (выходные дни), `leadMinutes` (за сколько минут минимум можно бронировать на сегодня — более раннее время блокируется), `maxDaysAhead`, `groupMax` + `groupMaxText` (максимум гостей и подсказка для больших компаний), `zones` (залы: `id` + `title`), `labels`, `perks`, `successTitle`, `successText`.
- Полоса быстрой брони (`type: "finder", mode: "table"`, если есть) переносит дату, время и гостей в форму и прокручивает к ней.
- Флажок согласия на обработку персональных данных **по умолчанию не отмечен** и ведёт на `privacy.html` — шаблон политики обработки ПД (Закон РБ № 99-З). Замените в нём реквизиты оператора, сроки хранения и перечень данных на фактические.
- Форма работает в демо-режиме (проверяет поля, показывает успех, **ничего не отправляет**). Чтобы получать заявки — укажите `endpoint` (Formspree, Getform, свой скрипт, вебхук Telegram-бота): форма отправит POST с JSON `name, phone, date, time, guests, service, comment, consent`.

## 7. SEO и пререндер (по желанию)

В `index.html` «запечена» готовая разметка для поисковиков и превью. После правок `config.js` обновите её (нужен Node.js): `npm i puppeteer && node tools/prerender.js`. Если забыть — сайт сам отрисует актуальный контент из `config.js`.
Для превью в соцсетях после публикации укажите в `meta.ogImage` полный адрес: `https://ваш-домен.by/assets/img/og-image.jpg`.

## 8. Публикация

- **Netlify:** перетащите папку на app.netlify.com/drop.
- **GitHub Pages:** загрузите содержимое папки в репозиторий → Settings → Pages → Branch: main / root.
- **Обычный хостинг:** загрузите содержимое папки в `public_html`.

## Особенности

- Адаптивность 320 px – 4K (проверено на 360 / 390 / 414 / 820 / 1280 / 1440 px), мобильное меню, нижняя панель «Позвонить / Забронировать» на телефонах, вкладки меню, просмотр фото на весь экран.
- WebP в двух размерах, `loading="lazy"`, шрифты локально, без библиотек и внешних запросов.
- Анимации только opacity/transform; при «уменьшить движение» (`prefers-reduced-motion`) отключаются.
- Доступность: семантичная разметка, управление с клавиатуры (в т.ч. просмотр фото), подписи для скринридеров.
