# Заметки по дизайну — «Чистая линия» (СТО №5)

**Референс:** https://www.ssense.com/ — люксовая мода, e-commerce и онлайн-журнал (fashion).
Взяты только принципы визуального стиля и интерфейса. Логотипы, тексты, фотографии и код референса **не использовались**; все фото — CC0 (см. `IMAGE-CREDITS.md`), тексты написаны с нуля, название компании вымышлено.

Скриншоты референса (для внутреннего использования): `/workspace/sites/_reference/ssense/` (в архив шаблона не входят).

## Что взято из референса (принципы)

- Чисто белый фон и чёрный текст — никаких цветовых акцентов; цвет дают только фотографии.
- Огромный гротеск капслоком с плотным трекингом (Onest) + антиква (PT Serif) для подзаголовков и подписей — «журнальная» пара.
- Логотип по центру шапки, мелкая навигация капслоком 11 px слева и справа.
- Первый экран как обложка: центрированный заголовок, подзаголовок-«лид» и две фотографии с подписями «рубрика — заголовок».
- Сетка карточек без фона, рамок и теней: фото, подпись, цена, тонкая чёрная линия.
- Тонкие чёрные линии-разделители, прямоугольные кнопки с 1px рамкой, скругления 0–3 px.
- Анимация — только прозрачность (fade), без движения.

## Чем этот шаблон отличается от остальных СТО-шаблонов

Монохром без акцентного цвета; логотип по центру; журнальный hero с двумя фото; гротеск капслоком + антиква; карточки без фона; только fade-анимации.

## Где что настраивается

- `theme.css` — цвета, шрифты, скругления.
- `skin.css` — раскладка и эффекты этого дизайна (переопределяет общий движок `core/core.css`).
- `config.js` — варианты блоков (`variant: ...`), тексты и порядок секций.
