# Шаблон сайта автосервиса (СТО)

Одностраничный адаптивный сайт на чистом HTML + CSS + JavaScript.
Без сборки и без зависимостей: откройте `index.html` двойным кликом — сайт работает.
Для публикации достаточно загрузить папку целиком на любой хостинг (GitHub Pages, Netlify, обычный хостинг) — все пути относительные, все файлы локальные.

> ⚠️ Всё наполнение — **демо-данные**: название «Гараж 24», телефоны, адрес, цены, отзывы и реквизиты вымышлены.

---

## Структура

```
sto/
├── index.html          ← каркас страницы (обычно не трогаем)
├── config.js           ← ВЕСЬ КОНТЕНТ: название, контакты, услуги, цены, тексты, отзывы, FAQ
├── theme.css           ← ВСЕ ЦВЕТА, шрифты, скругления (CSS-переменные)
├── assets/
│   ├── favicon.svg     ← иконка вкладки
│   └── img/            ← фотографии (WebP, по 2 размера: -640 и -1024)
├── core/               ← «движок»: одинаковый для всех шаблонов (СТО, стоматология, кафе…)
│   ├── core.css        ← вёрстка всех блоков
│   ├── core.js         ← отрисовка страницы из config.js + вся интерактивность
│   ├── icons.js        ← набор SVG-иконок
│   └── fonts/          ← шрифт Inter (локально, с кириллицей)
├── tools/
│   ├── optimize-images.py  ← подготовка своих фото
│   └── prerender.js        ← «запекание» HTML для SEO (необязательно)
└── docs/               ← заметки по дизайну, источники фото, инструкция по новым нишам
```

**Правило:** для нового клиента меняем только `config.js`, `theme.css` и файлы в `assets/`. Папку `core/` не трогаем.

## 1. Как поменять название, телефон, адрес

Откройте `config.js` в любом редакторе (VS Code, Notepad++, даже Блокнот) и измените значения в кавычках:

```js
brand: {
  name: "Гараж 24",          // название компании (для заголовков, копирайта)
  logo: null,                // путь к файлу логотипа или null
  logoText: "Гараж",         // текстовый логотип
  logoAccent: "24",          // часть логотипа в рамке (можно "")
  tagline: "Автосервис полного цикла"
},
contacts: {
  phone: "+375 (29) 000-00-00",   // как показывать
  phoneHref: "+375290000000",     // для звонка по клику: только + и цифры
  address: "г. Минск, ул. Примерная, 1",
  hours: [ { days: "Пн–Пт", time: "08:00–20:00" }, ... ],
  ...
}
```

Не забудьте также `meta.title` и `meta.description` (заголовок вкладки и описание для поисковиков) и `footer.legal` (реквизиты).

**Перед сдачей клиенту** поставьте `demo: false` в начале `config.js` — исчезнут пометки «пример» и «демо-режим».

## 2. Как поменять цвета и шрифт

Всё в `theme.css`. Главное — акцентный цвет:

```css
--color-accent: #0071e3;        /* кнопки, ссылки, иконки */
--color-accent-hover: #0a84ff;  /* кнопка при наведении (чуть светлее) */
--color-accent-soft: #e8f1fd;   /* светлая подложка под иконками (очень светлый оттенок акцента) */
```

Примеры: красный `#e0262d / #f0444a / #fdecec`, зелёный `#1f9d55 / #27b463 / #e7f6ee`, оранжевый `#f06a00 / #ff7f1a / #fff0e3`.

Скругления — `--radius-*` (поставьте 8px для более «строгого» вида). Шрифт — `--font-main`: чтобы подключить другой, положите файл `.woff2` в `core/fonts/` и добавьте `@font-face` в начало `theme.css`.

## 3. Как поставить логотип

1. Положите файл в `assets/`, например `assets/logo.svg` (лучше SVG или PNG с прозрачным фоном, высота ~80px).
2. В `config.js`: `brand.logo: "assets/logo.svg"`.
3. Иконку вкладки замените файлом `assets/favicon.svg` (или PNG, тогда поправьте строку `<link rel="icon">` в `index.html`).

## 4. Как менять тексты, услуги, цены

- **Услуги** — массив `services` в `config.js`. Каждая услуга: `title`, `text`, `price`, `time`, `icon`, `image`. Услуги автоматически попадают в карточки, в меню «Услуги», в мобильное меню, в футер и в список формы записи.
- **Цены** — блок `type: "prices"` → `categories` (вкладки) → `rows`: `["Название работы", "Цена"]`.
- **Отзывы, FAQ, шаги работы, преимущества, статистика** — соответствующие блоки в `sections`.
- **Порядок блоков** на странице = порядок в `sections`. Чтобы скрыть блок — добавьте `hidden: true`.
- Иконки: `diagnostics, engine, suspension, tire, oil, electrics, body, brakes, ac, wrench, car, shield, receipt, clock, coffee, award, users, card, percent, sparkles, calendar, pin, phone, mail` и др. (см. `core/icons.js`).

## 5. Как заменить фотографии

Каждое фото хранится в двух размерах: `name-640.webp` (для телефонов) и `name-1024.webp` (для ПК) — так сайт быстро грузится на мобильных.

**Вариант А (рекомендуется):**
```bash
pip install pillow
python3 tools/optimize-images.py мое-фото.jpg assets/img/svc-engine --ratio 4:3
```
Пропорции: карточки услуг и hero — `4:3`, баннер — `16:9`, «до/после» — `3:2`.

**Вариант Б (без программ):** пережмите фото на https://squoosh.app в WebP шириной 640 и 1024 px, сохраните как `имя-640.webp` и `имя-1024.webp`.

**Вариант В (просто):** укажите в `config.js` путь к одному файлу с расширением — `image: "assets/img/photo.jpg"` — он будет использован как есть (оптимизируйте размер до 200–300 КБ).

В `config.js` путь указывается **без** `-640.webp`: `image: "assets/img/svc-engine"`.

Блок «До/после»: для каждой работы нужны два фото одинакового кадра — `before` и `after`.

## 6. Карта

В `contacts.mapEmbed` вставьте ссылку из Яндекс Карт: «Поделиться → Виджет с картой» → скопируйте из кода iframe значение `src="…"`. Пока поле пустое, показывается аккуратная заглушка с кнопкой «Открыть на карте» (ссылка `contacts.mapLink`).

## 7. Форма записи — куда приходят заявки

Сейчас форма работает в демо-режиме: проверяет поля, показывает сообщение об успехе, но **никуда не отправляет данные**.
Чтобы получать заявки, укажите в блоке `booking` адрес обработчика: `endpoint: "https://formspree.io/f/xxxx"` (или Getform, Basin, свой PHP-скрипт, вебхук для Telegram-бота). Форма отправит POST-запрос с JSON: `name, phone, car, service, date, time, comment, consent`.

Настройки формы: маска телефона (`phoneMask`), время приёма (`timeSlots`), выходные дни (`closedWeekdays`: 0 — вс, 6 — сб), горизонт записи (`maxDaysAhead`).

## 8. SEO и пререндер (по желанию)

Контент рисуется из `config.js`, но в `index.html` уже «запечена» готовая разметка — её видят поисковики и превью в мессенджерах даже без JavaScript.
После правок `config.js` обновите её (нужен Node.js):
```bash
npm i puppeteer
node tools/prerender.js
```
Если забыть — ничего не сломается: сайт увидит, что `config.js` изменился, и отрисует актуальный контент сам (просто поисковики увидят старую версию разметки).

Для красивого превью ссылки в соцсетях после публикации укажите в `meta.ogImage` **полный** адрес картинки, напр. `https://ваш-домен.by/assets/img/og-image.jpg`.

## 9. Публикация

- **Netlify:** перетащите папку `sto` на app.netlify.com/drop.
- **GitHub Pages:** загрузите содержимое папки в репозиторий → Settings → Pages → Branch: main / root.
- **Обычный хостинг:** загрузите содержимое папки в `public_html` по FTP.

## Особенности

- Адаптивность: 320 px – 4K; мобильное меню, нижняя панель «Позвонить / Записаться» на телефонах.
- Производительность: WebP в двух размерах, `loading="lazy"`, шрифт локально, без библиотек. Анимации — только opacity/transform; при системной настройке «уменьшить движение» (`prefers-reduced-motion`) они отключаются, слайдер не прокручивается сам.
- Доступность: семантичная разметка, управление с клавиатуры, фокус в меню/модальном окне, подписи для скринридеров.
- SEO: готовая разметка «запечена» в `index.html` (см. раздел 8), заголовок и описание страницы — из `config.js → meta`.
