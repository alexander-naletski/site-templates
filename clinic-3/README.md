# Шаблон сайта медицинского центра №3 — «Норма»

Одностраничный адаптивный сайт клиники на чистом HTML + CSS + JavaScript — строгий монохромный стиль премиального автобренда.
Без сборки и без зависимостей: откройте `index.html` двойным кликом — сайт работает.
Для публикации загрузите папку целиком на любой хостинг (GitHub Pages, Netlify, обычный хостинг) — все пути относительные, все файлы локальные.

> ⚠️ Всё наполнение — **демо-данные**: название «Норма», город (Брест), телефоны, адрес, цены, врачи, лицензия, отзывы и реквизиты вымышлены. Люди на фото — модели фотостоков.
> Медицинская реклама: перед публикацией проверьте тексты на соответствие законодательству, укажите реальные номер лицензии и реквизиты. Строка «Имеются противопоказания, необходима консультация специалиста» уже есть в блоке лицензий, под программами и в подвале — не удаляйте её.

Дизайн создан по принципам сайта из другой отрасли: **https://www.polestar.com/** (электромобили (премиальный автобренд)). Логотипы, тексты и изображения референса не использовались — подробности в `docs/DESIGN-NOTES.md`.

## Структура

```
clinic-3/
├── index.html      ← каркас страницы (обычно не трогаем)
├── config.js       ← ВЕСЬ КОНТЕНТ: название, контакты, направления, программы, цены, врачи, тексты, отзывы, FAQ, лицензии
├── theme.css       ← ЦВЕТА, шрифты, скругления (CSS-переменные)
├── skin.css        ← оформление ЭТОГО дизайна: раскладка блоков, эффекты, анимации
├── assets/
│   ├── favicon.svg
│   ├── fonts/      ← шрифты дизайна (локально, с кириллицей, OFL)
│   └── img/        ← фотографии (WebP, по 2 размера: -640 и -1024) + og-image.jpg
├── core/           ← «движок»: общий для всех шаблонов (не редактировать)
├── tools/          ← optimize-images.py (подготовка фото), prerender.js (SEO)
├── screenshots/    ← превью шаблона (для витрины, на сайт не влияют — можно удалить)
└── docs/           ← заметки по дизайну и источники фото
```

**Правило:** для нового клиента меняем `config.js`, `theme.css` и файлы в `assets/`. `skin.css` — если нужно подправить внешний вид. Папку `core/` не трогаем.

## 1. Название, телефон, адрес, лицензия

Откройте `config.js` и измените значения в кавычках: `brand` (название, текстовый логотип), `contacts` (телефон, адрес, часы работы, соцсети), `meta.title` и `meta.description` (заголовок вкладки и описание для поисковиков), `footer.legal` (реквизиты, **номер лицензии Минздрава**), `footer.demoNote`, блок `type: "licenses"` (документы клиники).

**Перед сдачей клиенту** поставьте `demo: false` в начале `config.js` — исчезнут пометки «пример» и «демо-режим».

## 2. Цвета и шрифты

Всё в `theme.css`. Главное:

```css
--color-accent: #101010;        /* чёрный: кнопки */
--color-bg-soft: #f0f0f0;       /* серые плоскости */
/* --signal: #f06e00 — крошечный оранжевый акцент, в skin.css */
```

Шрифты: Geologica (вариативный 300–500, в `assets/fonts/`). Чтобы заменить шрифт — положите `.woff2` в `assets/fonts/`, поправьте `@font-face` в начале `theme.css` и переменные `--font-main` / `--font-heading`.

## 3. Блоки этого дизайна

Порядок блоков = порядок в `sections` в `config.js`; скрыть блок — `hidden: true`. Особенности этого шаблона:

- **Полоса-объявление** — `header.announce` + `announceHref` — тонкая серая строка над шапкой.
- **Первый экран** — `variant: "cover"` — полноэкранное фото, текст слева сверху, `titleAccent` — вторая строка заголовка серым, контурные кнопки.
- **Направления** — 2 в ряд, тонкие рамки, ссылка «Записаться →».
- **«С чего начать»** — `type: "links"` — огромный список ссылок со стрелками (`text`, `note`, `href`, `service` — что подставится в форму).
- **Обещание** — `type: "banner", variant: "full"` — тёмная полоса с фото на всю ширину.
- **Чек-апы** — `type: "programs"` без фото — минималистичные карточки с тонкой рамкой.
- **Врачи** — `type: "team"` без фото — монограммы на сером.

## 4. Направления, программы, цены, врачи

- **Направления (врачи и диагностика)** — массив `services`: `title`, `text`, `price`, `time`, `icon`, `image` (фото, нужно для этого дизайна). Направления автоматически попадают в блок, мобильное меню, подвал и список формы записи; клик подставляет направление в форму.
- **Программы (чек-апы)** — блок `type: "programs"` → `items`: `id` (обязательно — по нему программа попадает в список формы записи отдельной группой), `title`, `for` (для кого), `items` (что входит), `price`, `oldPrice`, `time`, `badge`, `icon`, `image`, `featured: true` — выделить. Настройки блока: `groupLabel` (название группы в форме), `priceLabel`, `buttonText`, `buttonStyle`, `note` (сноска), `rail: true` — горизонтальная лента.
- **Цены** — блок `type: "prices"` → `categories` → `rows`: `["Услуга", "Цена"]`.
- **Врачи** — блок `type: "team"` → `items`: `name`, `role`, `exp` (стаж), `text`, `tags`, `service` (что подставится в форму), `image` (необязательно — без фото рисуется монограмма из инициалов).
- **Лицензии** — блок `type: "licenses"` → `items`: `icon`, `title`, `text`; `note` — строка-предупреждение.
- **Отзывы, FAQ, шаги, статистика** — соответствующие блоки в `sections`.
- Медицинские иконки: `stethoscope, pulse, activity, flask, brain, bone, pill, ear, eye, female, baby, heart, lungs, syringe, file, video, home, search, shield, users, clock, calendar` и др. (см. `core/icons.js`).

## 5. Фотографии

Каждое фото хранится в двух размерах: `name-640.webp` и `name-1024.webp`. В `config.js` путь указывается **без** окончания: `image: "assets/img/svc-cardio"`.

```bash
pip install pillow
python3 tools/optimize-images.py мое-фото.jpg assets/img/svc-cardio --ratio 4:3
```

Пропорции в этом дизайне: первый экран — полноэкранное фото (`16:10`), **направления — `16:10`** (показ `16:9`), баннер-обещание — на всю ширину.
Без программ: пережмите фото на https://squoosh.app в WebP шириной 640 и 1024 px.
Фото реальных врачей и пациентов публикуйте только с их письменного согласия.

## 6. Карта и форма записи

- Карта: в `contacts.mapEmbed` вставьте `src` из кода виджета Яндекс Карт. Пока пусто — показывается заглушка с кнопкой «Открыть на карте» (`contacts.mapLink`).
- Форма работает в демо-режиме (проверяет поля, показывает успех, **ничего не отправляет**). Чтобы получать заявки — укажите `endpoint` в блоке `booking` (Formspree, Getform, свой скрипт, вебхук Telegram-бота): форма отправит POST с JSON `name, phone, service, date, time, comment, consent` (+ `car` — если включено дополнительное поле). Там же: `phoneMask`, `timeSlots`, `closedWeekdays` (0 — вс, 6 — сб), `maxDaysAhead`, `carField: false` — убрать дополнительное поле, `carOptional: true` — сделать его необязательным, подпись — `labels.car` (в клинике — «Врач» или «Пациент»).
- Персональные данные о здоровье — чувствительные: для реальной клиники используйте защищённый приём заявок и политику обработки персональных данных.

## 7. SEO и пререндер (по желанию)

В `index.html` «запечена» готовая разметка для поисковиков и превью. После правок `config.js` обновите её (нужен Node.js): `npm i puppeteer && node tools/prerender.js`. Если забыть — сайт сам отрисует актуальный контент из `config.js`.
Для превью в соцсетях после публикации укажите в `meta.ogImage` полный адрес: `https://ваш-домен.by/assets/img/og-image.jpg`.

## 8. Публикация

- **Netlify:** перетащите папку на app.netlify.com/drop.
- **GitHub Pages:** загрузите содержимое папки в репозиторий → Settings → Pages → Branch: main / root.
- **Обычный хостинг:** загрузите содержимое папки в `public_html`.

## Особенности

- Адаптивность 320 px – 4K (проверено на 360 / 390 / 414 / 820 / 1280 / 1440 px), мобильное меню, нижняя панель «Позвонить / Записаться» на телефонах, горизонтальные ленты со свайпом.
- WebP в двух размерах, `loading="lazy"`, шрифты локально, без библиотек и внешних запросов.
- Анимации только opacity/transform; при «уменьшить движение» (`prefers-reduced-motion`) отключаются.
- Доступность: семантичная разметка, управление с клавиатуры, подписи для скринридеров.

Фото — CC0 (см. `docs/IMAGE-CREDITS.md`). Шрифты — SIL OFL 1.1.

**Реклама медицинских услуг (РБ).** Блоки «до/после» и фото результатов лечения в шаблоне не используются: законодательство о рекламе может запрещать ссылки на конкретные случаи излечения и улучшения состояния здоровья. Вместо них — нейтральная галерея клиники и оборудования. Отзывы пациентов перед публикацией также согласуйте с юристом.

**Персональные данные.** Во всех формах есть флажок согласия (по умолчанию не отмечен) со ссылкой на `privacy.html` — шаблон политики обработки персональных данных. Замените в нём реквизиты оператора, сроки хранения и перечень данных на фактические.
