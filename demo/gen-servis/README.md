# Сайт «ГенСервис» — автосервис, Минск, ул. Кальварийская, 33 к14

Готовый к публикации сайт станции техобслуживания «ГенСервис». Одна страница + `privacy.html` + `404.html`, без сборки и без библиотек: можно залить на любой статический хостинг.

**Статус: концепт до согласования с владельцем.**

- В подвале строка «Концепт сайта для ГенСервис». Она задаётся `conceptNote` в `config.js`; `null` её убирает.
- Сайт закрыт от поисковиков (`noindex`, см. раздел 8).
- Форма заявок не подключена (см. раздел 7). Пока посетитель отправляет форму, она честно предлагает позвонить или написать в Telegram.

**Включить индексацию — одна строка:** в `config.js` поменять `seo: { … indexing: false }` на `indexing: true`, затем выполнить `node tools/seo.js` (или `node tools/prerender.js`, он вызывает seo.js сам).

**Откуда контент:**

- Все тексты, цены, часы, телефоны и рейтинги взяты из открытых источников самого сервиса (на 02.10.2026):
  - карточка на Яндекс Картах (раздел «Товары и услуги», фирменный прайс-лист, особенности);
  - Telegram-канал @stogenservice;
  - 2ГИС;
  - интервью директора порталу butikavto.by.
- Источники и открытые вопросы перечислены в `PITCH.md` (в публикацию не входит).
- Фото опубликованы самим сервисом: `docs/IMAGE-CREDITS.md`.
- Отзывы — короткие дословные выдержки с Яндекс Карт со ссылкой на все отзывы.

**Техника:**

- Основа — шаблон СТО №1 (`sites/sto`). Цвет — фирменный красный из логотипа (#e30613). Шрифт — Inter.
- Движок `core/` — **v1.7** (только в этой копии). Нового в v1.7:
  - подключаемые формы `forms.endpoint`: Formspree-совместимый JSON POST, таймаут, ловушка для ботов, понятные сообщения об успехе и ошибке;
  - строка `conceptNote`;
  - `seo.indexing`;
  - кнопка «Построить маршрут» под картой;
  - сноска и кнопка под отзывами и галереей;
  - заметки к вкладкам цен;
  - иконка TikTok;
  - ссылки-мессенджеры в блоке записи.

## 1. Как поменять название, телефон, адрес

Откройте `config.js` в любом редакторе (VS Code, Notepad++, даже Блокнот) и измените значения в кавычках:

```js
brand: {
  name: "Гараж 24",          // название компании (для заголовков, копирайта)
  logo: null,                // путь к файлу логотипа или null
  logoText: "Гараж",         // текстовый логотип
  logoAccent: "24",          // часть логотипа в рамке (можно "")
  tagline: "Автосервис полного цикла"
},
contacts: {
  phone: "+375 (29) 000-00-00",   // как показывать
  phoneHref: "+375290000000",     // для звонка по клику: только + и цифры
  address: "г. Минск, ул. Примерная, 1",
  hours: [ { days: "Пн–Пт", time: "08:00–20:00" }, ... ],
  ...
}
```

Не забудьте также `meta.title` и `meta.description` (заголовок вкладки и описание для поисковиков) и `footer.legal` (реквизиты).

Сейчас стоит `demo: false` (рабочий режим). Строка «Концепт сайта для ГенСервис» в подвале задаётся `conceptNote` в начале `config.js` — после согласования поставьте `conceptNote: null`.

## 2. Как поменять цвета и шрифт

Всё в `theme.css`. Главное — акцентный цвет:

```css
--color-accent: #0071e3;        /* кнопки, ссылки, иконки */
--color-accent-hover: #0a84ff;  /* кнопка при наведении (чуть светлее) */
--color-accent-soft: #e8f1fd;   /* светлая подложка под иконками (очень светлый оттенок акцента) */
```

Примеры: красный `#e0262d / #f0444a / #fdecec`, зелёный `#1f9d55 / #27b463 / #e7f6ee`, оранжевый `#f06a00 / #ff7f1a / #fff0e3`.

Скругления — `--radius-*` (поставьте 8px для более «строгого» вида). Шрифт — `--font-main`: чтобы подключить другой, положите файл `.woff2` в `core/fonts/` и добавьте `@font-face` в начало `theme.css`.

## 3. Как поставить логотип

Сейчас логотип текстовый: «Ген» красным + «Сервис», перед ним значок «ГС» (`assets/favicon.svg`). Стиль задан в конце `theme.css`. Когда владелец пришлёт исходник своего знака:

1. Положите файл в `assets/`, например `assets/logo.svg` (лучше SVG или PNG с прозрачным фоном, высота ~80px).
2. В `config.js`: `brand.logo: "assets/logo.svg"`.
3. Иконку вкладки замените файлом `assets/favicon.svg` (или PNG, тогда поправьте строку `<link rel="icon">` в `index.html`).

## 4. Как менять тексты, услуги, цены

- **Услуги** — массив `services` в `config.js`. Каждая услуга: `title`, `text`, `price`, `time`, `icon`, `image`. Услуги автоматически попадают в карточки, в меню «Услуги», в мобильное меню, в футер и в список формы записи.
- **Цены** — блок `type: "prices"` → `categories` (вкладки) → `rows`: `["Название работы", "Цена"]`.
- **Отзывы, FAQ, шаги работы, преимущества, статистика** — соответствующие блоки в `sections`.
- **Порядок блоков** на странице = порядок в `sections`. Чтобы скрыть блок — добавьте `hidden: true`.
- Иконки: `diagnostics, engine, suspension, tire, oil, electrics, body, brakes, ac, wrench, car, shield, receipt, clock, coffee, award, users, card, percent, sparkles, calendar, pin, phone, mail` и др. (см. `core/icons.js`).

## 5. Как заменить фотографии

Каждое фото хранится в двух размерах: `name-640.webp` (для телефонов) и `name-1024.webp` (для ПК) — так сайт быстро грузится на мобильных.

**Вариант А (рекомендуется):**
```bash
pip install pillow
python3 tools/optimize-images.py мое-фото.jpg assets/img/svc-engine --ratio 4:3
```
Пропорции: карточки услуг и hero — `4:3`, баннер — `16:9`, «до/после» — `3:2`.

**Вариант Б (без программ):** пережмите фото на https://squoosh.app в WebP шириной 640 и 1024 px, сохраните как `имя-640.webp` и `имя-1024.webp`.

**Вариант В (просто):** укажите в `config.js` путь к одному файлу с расширением — `image: "assets/img/photo.jpg"` — он будет использован как есть (оптимизируйте размер до 200–300 КБ).

В `config.js` путь указывается **без** `-640.webp`: `image: "assets/img/svc-engine"`.

Блок «До/после»: для каждой работы нужны два фото одинакового кадра — `before` и `after`.

## 6. Карта

`contacts.mapEmbed` — официальный виджет Яндекс Карт с карточкой организации (`oid=101538386997`): рейтинг, адрес, телефон, метро, кнопка «Как добраться».
Под картой — кнопка «Построить маршрут» (`contacts.routeLink`) и ссылка на отзывы и фото (`contacts.mapLinkButton`). Если `mapEmbed` очистить, вместо карты будет аккуратная заглушка с кнопкой «Открыть на карте».

## 7. Заявки с сайта: e-mail или Telegram

Пока `forms.endpoint` пустой, обе формы («Онлайн-запись» и «Заказать звонок»):

1. проверяют поля, без галочки согласия заявка не уходит;
2. **открывают Telegram-чат @stoGenServis с готовым текстом заявки** (`forms.prefill`): клиенту остаётся нажать «Отправить»;
3. показывают запасные кнопки «Открыть Telegram / Отправить по SMS / Позвонить / Скопировать текст»;
4. на сервер ничего не отправляют и не делают вид, что заявка ушла.

Если поставить `prefill: null`, вместо этого появится сообщение «Онлайн-заявки скоро заработают…» со ссылками на телефон и Telegram.

Подключение подробно описано в **`docs/FORMS.md`**. Коротко:

- **На e-mail (Formspree):**
  1. Зарегистрироваться на formspree.io и создать форму.
  2. Вписать её адрес: `forms: { endpoint: "https://formspree.io/f/abcdwxyz" }`.
  3. Подтвердить почту в письме от Formspree.
- **В Telegram:**
  1. Создать бота у @BotFather.
  2. Развернуть `tools/telegram-worker.js` на Cloudflare Workers (бесплатно) с переменными `BOT_TOKEN`, `CHAT_ID`, `ALLOWED_ORIGIN`.
  3. Вписать адрес воркера в `forms.endpoint`.
  4. Токен бота в код сайта **не вставлять** никогда.

Форма отправляет JSON POST. Поля:

- запись: `name, phone, car, service` + `serviceTitle`, `date, time, comment, consent`;
- звонок: `cbname, cbphone, consent`;
- служебные: `form` (`booking`/`callback`), `_subject`, `page`.

Ответ `2xx` (и не `{"ok":false}`) считается успехом. Ошибка или таймаут (`forms.timeoutMs`, по умолчанию 15 с) показывает сообщение с телефоном, а данные в форме сохраняются.

Скрытое поле `_gotcha` — ловушка для ботов: если оно заполнено, заявка не отправляется.

Прочие настройки формы:

- маска телефона `phoneMask`;
- время приёма `timeSlots`;
- выходные `closedWeekdays`;
- горизонт записи `maxDaysAhead`.

## 8. SEO

- `index.html` содержит «запечённую» разметку страницы (`node tools/prerender.js`, нужен `npm i puppeteer`) и SEO-блок между `<!--SEO:START-->` и `<!--SEO:END-->`. SEO-блок включает:
  - `title`, `description`;
  - `robots`;
  - Open Graph;
  - иконки;
  - JSON-LD `AutoRepair`: адрес, координаты, телефоны, часы, оплата, удобства, цены из прайса, ссылки на Яндекс/2ГИС/Telegram/Instagram.
- Блок, `sitemap.xml` и `robots.txt` генерирует **`node tools/seo.js`** из `config.js` (нужен только Node.js). `prerender.js` вызывает его сам.
- **Индексация:** `seo.indexing: false` → `<meta name="robots" content="noindex, nofollow">`. `robots.txt` обход не запрещает: иначе поисковик не увидит `noindex`.
  - При `true` сайт открыт, в `robots.txt` появляется `Sitemap:`, добавляются `canonical`, `og:url` и полный адрес `og:image`.
- **Домен:** `seo.siteUrl` (сейчас `https://genservice.by/`, **не подтверждён** — см. PITCH.md). Поменять и выполнить `node tools/seo.js`.
- **Превью ссылок, пока сайт закрыт:** `seo.previewUrl` (сейчас адрес на GitHub Pages). Пока `indexing:false`, og:url и og:image строятся от него, иначе картинка-превью в Telegram и Viber не подтянется. После запуска на своём домене `seo.previewUrl` можно удалить.
- Рейтинг (`aggregateRating`) в JSON-LD **намеренно не размечен**: правила Google не разрешают размечать оценки, собранные на сторонних площадках. Рейтинг показан на странице обычным текстом со ссылками.
- После публикации стоит добавить сайт в Яндекс Вебмастер и Google Search Console, а в карточке на Яндекс Картах указать адрес сайта.

## 9. Публикация

Загрузите содержимое папки (без `screenshots/`, `PITCH.md`, `node_modules/`) на хостинг: Netlify Drop, GitHub Pages, Cloudflare Pages или обычный хостинг по FTP.

`404.html` использует абсолютные ссылки (`/`, `/assets/…`), поэтому корректно работает, когда сайт лежит в корне домена. Настройка хостинга:

- Netlify, GitHub Pages и Cloudflare Pages подхватывают 404.html сами;
- на Apache нужно добавить `ErrorDocument 404 /404.html`.

## Особенности

- Адаптивность: 320 px – 4K; мобильное меню; нижняя панель «Позвонить / Записаться» на телефонах.
- Производительность:
  - WebP в двух размерах, `loading="lazy"`, шрифт локально, без библиотек;
  - карта грузится лениво, только при прокрутке к контактам.
- Доступность: семантичная разметка, управление с клавиатуры, фокус в меню и модальном окне, подписи для скринридеров, alt у всех фото.
- Персональные данные: флажок согласия в формах (по умолчанию снят) и `privacy.html`. Наименование оператора и УНП нужно вписать после согласования.
