# Дизайн-заметки: референс i-store.by (сент. 2026)

Изучено: HTML/CSS главной страницы, скриншоты 1440px и 390px (headless Chrome), вычисленные стили.
С сайта взяты **только принципы оформления** — ни логотипы, ни тексты, ни изображения не копировались.

## Общий характер
Светлый «Apple-подобный» минимализм: много белого, мягкие серые подложки, один яркий синий акцент,
крупные скругления, спокойная типографика, почти нет декоративных элементов.

## Палитра (вычисленные значения)
| Роль | Цвет |
|---|---|
| Основной текст / заголовки | `#222228` (заголовки), `#555558` (текст) |
| Акцент (кнопки) | `#0071e3`, ссылки/иконки `#007aff` |
| Светлая подложка секций | `#f8f8fc`, `#f3f3f3` |
| Рамки | `#ebecef` (inset 1px) |
| Тёмная верхняя полоса | `#131313` / чёрный |
| Второстепенный текст | `#898989`, `rgba(34,34,40,.4)` |

## Типографика
- SF UI Display → в шаблоне заменён на Inter (OFL, локально, кириллица) с fallback на системный стек.
- body 16px/400; H1 32px/500; H2 24px/500; навигация 13–15px/500–590. Заголовки не жирные (500), сдержанные.

## Шапка
- Тонкая тёмная верхняя полоса (инфо-ссылки слева, телефон + «Заказать звонок» справа).
- Основная строка: логотип, синяя кнопка-«пилюля» «Каталог» с иконкой-бургером, широкий поиск-пилюля на сером фоне, иконки с подписями.
- Вторая строка — горизонтальное меню категорий, справа отделено вертикальным разделителем.
- Тень шапки: `0 5px 30px rgba(34,34,40,.08)`.

## Hero
- Баннер-слайдер во всю ширину контейнера (1360px), радиус 24px, светлый фон, крупный заголовок, точки-пагинация (активная — вытянутая черта) и круглые стрелки внизу справа.

## Карточки
- Радиус 24px (основной), 12px (мелкие). Белые карточки с рамкой 1px `#ebecef` на сером фоне секции.
- Карточки преимуществ: контурная синяя иконка сверху, жирный заголовок, серый мелкий текст.
- Плитки категорий: серый квадрат с картинкой, подпись под ним; горизонтальная карусель со стрелками-кружками.
- Промо-карточки: фото на всю карточку, градиент снизу, белый текст.
- Широкий фото-баннер «Центр компетенций» с затемнением и прозрачной кнопкой с белой рамкой.

## Кнопки
- Пилюли (radius 32px), padding 10×16, 13px/590, синий фон, белый текст; hover — светлее/прозрачность.
- Вторичные: прозрачные с серой рамкой `rgba(85,85,88,.32)`.

## Анимации
- Короткие transition 0.2–0.3s (цвет, тень, transform), opacity 0.6s для появлений. Никаких тяжёлых эффектов.

## Футер
- Колонки ссылок с жирными заголовками, контакты с адресами и часами, логотип + круглые иконки соцсетей, юр. информация мелким текстом, копирайт по центру.

## Мобильная версия
- Шапка схлопывается: бургер слева, логотип, иконки телефона/поиска справа. Баннеры и карусели — свайп.

## Что адаптировано для СТО
- Акцент тот же «чистый синий», но вынесен в CSS-переменную (легко сменить).
- «Каталог» → «Услуги», поиск → телефон/режим работы, иконки → запись/звонок/адрес.
- Плитки категорий → карточки услуг с фото; блок преимуществ 1:1 по стилю; промо-баннер → фото-баннер техцентра; добавлены прайс, до/после, отзывы, FAQ, форма записи.
- На мобильных: нижняя фиксированная панель «Позвонить / Записаться» вместо чат-кнопки.
