# Подключение заявок с сайта

> **Сейчас (без сервера):** `forms.prefill: { telegram: "stoGenServis", sms: "+375296348444" }`. Обе формы открывают Telegram с готовым текстом заявки (в Telegram используется ссылка `https://t.me/<user>?text=…`), запасной вариант — SMS. Чтобы сменить получателя, замените `telegram`. Как только в `forms.endpoint` появится адрес сервера (варианты ниже), формы начнут отправлять заявки туда, а `prefill` перестанет использоваться.

На сайте две формы: **«Онлайн-запись»** (блок `booking`) и **«Заказать звонок»** (окно из шапки). Обе отправляют заявку на один адрес — `forms.endpoint` в `config.js`. У отдельной формы можно задать свой адрес: `endpoint` у секции `booking` или у `callback`.

```js
forms: {
  endpoint: "",                         // ← сюда адрес приёма заявок
  subject: "Заявка с сайта ГенСервис",  // тема письма (Formspree понимает поле _subject)
  timeoutMs: 15000,                     // сколько ждать ответа сервера
  messengerUrl: "https://t.me/stoGenServis",  // ссылка в сообщениях «не подключено» и «ошибка»
  ...
}
```

## Как ведёт себя форма

| Состояние | Что видит посетитель |
|---|---|
| `endpoint` пустой, `prefill` задан (сейчас так) | Поля проверяются, галочка согласия обязательна. Затем открывается Telegram-чат @stoGenServis с готовым текстом заявки: посетителю остаётся нажать «Отправить». Под формой появляются запасные кнопки «Открыть Telegram / Отправить по SMS / Позвонить / Скопировать текст». Сервер не нужен. |
| `endpoint` пустой и `prefill: null` | Заявка **не отправляется**. Сообщение: «Онлайн-заявки скоро заработают. Пока, пожалуйста, позвоните или напишите нам: +375 (29) 634-84-44 или Telegram». |
| Отправка | Кнопка блокируется и показывает индикатор загрузки (защита от двойного клика). |
| Сервер ответил `2xx` | «Запись»: экран «Заявка отправлена» со сводкой (имя, телефон, авто, услуга, дата). «Звонок»: «Спасибо! Мы перезвоним в рабочее время», окно закрывается. |
| Ошибка сети, ответ `4xx`/`5xx`, `{"ok":false}` или таймаут | Сообщение «Не удалось отправить заявку… свяжитесь с нами напрямую» со ссылками на телефон и Telegram. Введённые данные **сохраняются**, можно повторить. |
| Бот заполнил скрытое поле `_gotcha` | Делаем вид, что всё отправлено; на сервер ничего не уходит. |

Тело запроса — JSON (`Content-Type: application/json`, `Accept: application/json`):

```json
{
  "name": "Иван", "phone": "+375 (29) 111-22-33", "car": "Mazda 6, 2010",
  "service": "alignment", "serviceTitle": "3D развал-схождение",
  "date": "2026-10-05", "time": "10:30", "timeTitle": "10:30",
  "comment": "тянет вправо", "consent": true,
  "form": "booking", "_subject": "Заявка с сайта ГенСервис — запись",
  "page": "https://genservice.by/"
}
```

Форма «звонок» отправляет `cbname`, `cbphone`, `consent`, `form: "callback"`.

## Вариант 1. На e-mail через Formspree (5 минут, без программирования)

1. Зарегистрируйтесь на https://formspree.io, нажмите **New form** и укажите почту, на которую должны приходить заявки.
2. Скопируйте адрес формы вида `https://formspree.io/f/abcdwxyz`.
3. В `config.js`: `forms: { endpoint: "https://formspree.io/f/abcdwxyz", … }`.
4. Отправьте тестовую заявку с опубликованного сайта и подтвердите почту по письму от Formspree.
5. В настройках формы на Formspree укажите домен сайта в **Restrict to domain**: так чужие сайты не смогут слать спам на ваш адрес.

Бесплатного тарифа Formspree (на момент написания — 50 заявок в месяц) обычно хватает на старте. Подойдёт любой совместимый сервис, который принимает JSON POST и отвечает `2xx`: Getform, Basin, свой PHP-скрипт.

## Вариант 2. В Telegram (бот + Cloudflare Worker, ~10 минут)

Токен бота нельзя класть в код сайта: его увидит любой посетитель. Поэтому между сайтом и Telegram стоит маленький бесплатный «посредник» — `tools/telegram-worker.js`.

1. **Бот.** В Telegram откройте @BotFather → `/newbot` → придумайте имя и получите **токен**.
2. **Чат.** Добавьте бота в рабочую группу (например, «Заявки ГенСервис») или напишите ему сами. Чтобы узнать `chat_id`:
   - откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":…}`;
   - у групп id начинается с `-100…`.
3. **Воркер.** Зайдите на https://dash.cloudflare.com → **Workers & Pages** → **Create** → **Create Worker**. Замените код содержимым `tools/telegram-worker.js` и нажмите **Deploy**.
4. **Переменные.** В воркере откройте **Settings → Variables and Secrets** и добавьте:
   - `BOT_TOKEN` — тип **Secret**, значение — токен бота;
   - `CHAT_ID` — id чата из шага 2;
   - `ALLOWED_ORIGIN` — адрес сайта без слеша в конце, например `https://genservice.by`. Можно перечислить несколько через запятую.
5. Скопируйте адрес воркера (`https://….workers.dev`) в `config.js → forms.endpoint`.
6. Отправьте тестовую заявку. В чат придёт сообщение «🛠 Запись на сервис» с полями заявки.

Что делает воркер:

- принимает только POST с разрешённого адреса (CORS);
- проверяет телефон;
- отбрасывает ботов (`_gotcha`);
- экранирует текст и обрезает слишком длинные поля;
- отвечает `{"ok":true}`, а при ошибке — `{"ok":false}` с кодом 4xx/5xx. Сайт в этом случае покажет посетителю сообщение с телефоном.

Можно совместить оба способа: письмо через Formspree плюс уведомление в Telegram через его интеграции (или доработать воркер, чтобы он слал и туда, и туда).

## Проверка после подключения

- [ ] Тестовая заявка «Онлайн-запись» пришла, услуга и дата читаются.
- [ ] Тестовый «Заказать звонок» пришёл.
- [ ] При выключенном интернете (DevTools → Offline) форма показывает ошибку с телефоном и сохраняет введённые данные.
- [ ] В `privacy.html` указаны оператор (наименование, УНП) и сервис, через который идут заявки.
