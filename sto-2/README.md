# Шаблон сайта автосервиса №2 — «МоторЛаб»

Одностраничный адаптивный сайт на чистом HTML + CSS + JavaScript — тёмный «технологичный» стиль SaaS-продуктов.
Без сборки и без зависимостей: откройте `index.html` двойным кликом — сайт работает.
Для публикации загрузите папку целиком на любой хостинг (GitHub Pages, Netlify, обычный хостинг) — все пути относительные, все файлы локальные.

> ⚠️ Всё наполнение — **демо-данные**: название «МоторЛаб», телефоны, адрес, цены, отзывы и реквизиты вымышлены.

Дизайн создан по принципам сайта из другой отрасли: **https://linear.app/** (SaaS / инструмент для управления проектами (tech-продукт)). Логотипы, тексты и изображения референса не использовались — подробности в `docs/DESIGN-NOTES.md`.

## Структура

```
sto-2/
├── index.html      ← каркас страницы (обычно не трогаем)
├── config.js       ← ВЕСЬ КОНТЕНТ: название, контакты, услуги, цены, тексты, отзывы, FAQ
├── theme.css       ← ЦВЕТА, шрифты, скругления (CSS-переменные)
├── skin.css        ← оформление ЭТОГО дизайна: раскладка блоков, эффекты, анимации
├── assets/
│   ├── favicon.svg
│   ├── fonts/      ← шрифты дизайна (локально, с кириллицей, OFL)
│   └── img/        ← фотографии (WebP, по 2 размера: -640 и -1024)
├── core/           ← «движок»: общий для всех шаблонов (не редактировать)
├── tools/          ← optimize-images.py (подготовка фото), prerender.js (SEO)
└── docs/           ← заметки по дизайну и источники фото
```

**Правило:** для нового клиента меняем `config.js`, `theme.css` и файлы в `assets/`. `skin.css` — если нужно подправить внешний вид. Папку `core/` не трогаем.

## 1. Название, телефон, адрес

Откройте `config.js` и измените значения в кавычках: `brand` (название, текстовый логотип), `contacts` (телефон, адрес, часы работы, соцсети), `meta.title` и `meta.description` (заголовок вкладки и описание для поисковиков), `footer.legal` (реквизиты).

**Перед сдачей клиенту** поставьте `demo: false` в начале `config.js` — исчезнут пометки «пример» и «демо-режим».

## 2. Цвета и шрифты

Всё в `theme.css`. Главное:

```css
--color-accent: #7b83f7;        /* индиго: ссылки, иконки, статусы */
--color-accent-hover: #969cff;
--color-accent-soft: rgba(123, 131, 247, .14);
```

Шрифты: Inter (в `core/fonts/`) + JetBrains Mono для цифр и меток (в `assets/fonts/`). Чтобы заменить шрифт — положите `.woff2` в `assets/fonts/`, поправьте `@font-face` в начале `theme.css` и переменные `--font-main` / `--font-heading`.

## 3. Блоки этого дизайна

Порядок блоков = порядок в `sections` в `config.js`; скрыть блок — `hidden: true`. Особенности этого шаблона:

- **Шапка** — `header: { variant: "bar", ctaStyle: "light" }` — однострочная, полупрозрачная с размытием.
- **Первый экран** — `variant: "centered"` — бейдж, крупный заголовок с градиентом и «интерфейс» заказ-наряда (`mockup`: этапы, прогресс, свойства). Меняйте тексты этапов в `mockup.steps`, `state`: `done` / `active` / `todo`.
- **Логотипы марок** — `type: "marquee", static: true` — строка марок.
- **Манифест** — `type: "statement"` — крупный текст, вторая часть (`muted`) приглушена.
- **Услуги** — `variant: "bento"` — сетка карточек; `wide: true` у услуги делает карточку широкой (для ровной сетки: в каждом ряду 3 «ячейки», широкая = 2).
- **Отзывы** — `variant: "grid"` — первые две карточки цветные (лаванда и лайм). Оптимально 5 или 8 отзывов, чтобы сетка была ровной.

## 4. Услуги, цены, тексты

- **Услуги** — массив `services`: `title`, `text`, `price`, `time`, `icon` (`image` в этом дизайне не используется — можно не указывать). Услуги автоматически попадают в блок услуг, мобильное меню, подвал и список формы записи; клик по услуге подставляет её в форму.
- **Цены** — блок `type: "prices"` → `categories` → `rows`: `["Работа", "Цена"]`.
- **Отзывы, FAQ, шаги, статистика** — соответствующие блоки в `sections`.
- Иконки: `diagnostics, engine, suspension, tire, oil, electrics, body, brakes, ac, wrench, car, shield, receipt, clock, users, sparkles, calendar, eye, zap, gauge, layers` и др. (см. `core/icons.js`).

## 5. Фотографии

Каждое фото хранится в двух размерах: `name-640.webp` и `name-1024.webp`. В `config.js` путь указывается **без** окончания: `image: "assets/img/svc-engine"`.

```bash
pip install pillow
python3 tools/optimize-images.py мое-фото.jpg assets/img/svc-engine --ratio 4:5
```

Пропорции в этом дизайне: баннер — `16:9`, «О нас» — `4:3`, «до/после» — `3:2`. У услуг в этом дизайне фото нет (сетка «бенто» с иконками).
Без программ: пережмите фото на https://squoosh.app в WebP шириной 640 и 1024 px. Блок «До/после»: два фото одного кадра — `before` и `after`.

## 6. Карта и форма записи

- Карта: в `contacts.mapEmbed` вставьте `src` из кода виджета Яндекс Карт. Пока пусто — показывается заглушка с кнопкой «Открыть на карте» (`contacts.mapLink`).
- Форма работает в демо-режиме (проверяет поля, показывает успех, **ничего не отправляет**). Чтобы получать заявки — укажите `endpoint` в блоке `booking` (Formspree, Getform, свой скрипт, вебхук Telegram-бота): форма отправит POST с JSON `name, phone, car, service, date, time, comment, consent`. Там же: `phoneMask`, `timeSlots`, `closedWeekdays` (0 — вс, 6 — сб), `maxDaysAhead`.

## 7. SEO и пререндер (по желанию)

В `index.html` «запечена» готовая разметка для поисковиков и превью. После правок `config.js` обновите её (нужен Node.js): `npm i puppeteer && node tools/prerender.js`. Если забыть — сайт сам отрисует актуальный контент из `config.js`.
Для превью в соцсетях после публикации укажите в `meta.ogImage` полный адрес: `https://ваш-домен.by/assets/img/og-image.jpg`.

## 8. Публикация

- **Netlify:** перетащите папку на app.netlify.com/drop.
- **GitHub Pages:** загрузите содержимое папки в репозиторий → Settings → Pages → Branch: main / root.
- **Обычный хостинг:** загрузите содержимое папки в `public_html`.

## Особенности

- Адаптивность 320 px – 4K, мобильное меню, нижняя панель «Позвонить / Записаться» на телефонах.
- WebP в двух размерах, `loading="lazy"`, шрифты локально, без библиотек и внешних запросов.
- Анимации только opacity/transform; при «уменьшить движение» (`prefers-reduced-motion`) отключаются.
- Доступность: семантичная разметка, управление с клавиатуры, подписи для скринридеров.

Фото — CC0 (см. `docs/IMAGE-CREDITS.md`). Шрифты — SIL OFL 1.1.

**Персональные данные.** Во всех формах есть флажок согласия (по умолчанию не отмечен) со ссылкой на `privacy.html` — шаблон политики обработки персональных данных. Замените в нём реквизиты оператора, сроки хранения и перечень данных на фактические.
